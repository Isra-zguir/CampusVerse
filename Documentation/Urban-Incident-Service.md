# Urban Incident & Maintenance Management

**Backend:** `Backend/urban-incident-service`  
**Frontend:** `Frontend/urban-incidents`  
**Tech:** Spring Boot 4 · Java 21 · H2 · Angular 21  
**Port:** 8082

Municipal agents and citizens use this service to report, classify, validate and repair urban problems (potholes, broken streetlights, water leaks, etc.).

This folder currently contains the **project structure** (entities from the UML class diagram, empty services/controllers, Angular pages). Business logic will be added later.

See the class diagram in [Diagrams/urban-incident-class.md](Diagrams/urban-incident-class.md).
